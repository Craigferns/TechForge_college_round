## What this pass added beyond the 30 rules
- **Before/after remediation (G):** each measured fix records `before_runs`/`after_runs` per case (additive API fields). Remediation shows a per-case table: base-policy outcome, fixed-policy outcome, and a change label (Blocked by fix, Still exploitable, Broken by fix, Unchanged, Inconclusive), with links to both runs. Verified live after a UI retest: AS-03 went from exploited to resisted ("Blocked by fix") and 10/10 benign tasks passed both before and after.
- **Report export (H):** Markdown, JSON (the persisted report record) and standalone HTML. A test intercepts the generated files: the JSON parses, and the HTML is a full document with tables and no `<script>`.
- **Finding detail:** split into "Observed: state change in the latest run" and "Interpretation" (the severity rule and the reason for the status).
- **Disabled-state and scrim tokens:** disabled buttons use `--disabled-*` tokens instead of opacity fading.
- **Route change:** a 140 ms fade-in with no exit delay, honouring reduced motion.
